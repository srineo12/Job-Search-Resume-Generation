# Job Search & Resume Generation

An automated job search and resume generation system that scrapes job listings, ranks them by relevance, and generates tailored resumes and cover letters.

## Overview

This project provides an end-to-end pipeline for job seekers:

- Import job listings via Apify web scraping
- Rank and filter jobs based on configurable rules
- Generate customized resumes and cover letters using AI
- Store generated documents to Google Drive
